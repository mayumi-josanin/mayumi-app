# サーバーPCの電源設定

**2026-09-07。停電で46分止まったのを機に見直した記録。**

サーバーPC（`desktop-rmsk0vg`）は自宅にあり、**止まっても誰も気づけない。**
だから、止まりにくくし、止まっても戻るようにしておく。

---

## 何が起きたか（2026-09-07）

```
7:51   予期しないシャットダウン（イベント ID 6008）
8:37   自動で復帰（ID 41）
```

**46分間、サーバーが止まっていた。**そのあいだ、お客様のアプリは
お知らせ・商品・カレンダーを読めなかった（9/5 にサーバーへ移したため）。

**データは無事だった。**日次の控えも取れていた。
BIOS の「電源復帰時に自動起動」は効いている。

---

## 直したこと

| | 前 | 後 | なぜ |
|---|---|---|---|
| 高速スタートアップ | 有効 | **無効** | 停電で落ちると、途中まで眠った状態が壊れて起動に失敗することがある |
| 電源プラン | バランス | **高パフォーマンス** | 予期しない省電力動作を防ぐ |
| ディスクの停止 | **20分** | **しない** | **データベースが載っているディスクが止まっていた** |
| Update の再起動 | 6:00〜15:00 は避ける | **6:00〜23:00 は避ける** | 15時以降の**診療中に再起動される**恐れがあった |

スリープと休止は元から「しない」だった。

### ディスクの停止が20分だったこと

いちばん驚いた。`0x4b0` = 1200秒。**PostgreSQL が載っているディスクが
20分で止まる設定**になっていた。実害が出ていたかは分からないが、
応答が遅い・接続が切れるといった形で出ていた可能性がある。

## まだやっていないこと

### UPS（無停電電源）— **院長のご判断待ち**

いま**バッテリーは付いていない。**停電するとその場で落ちる。

```
5分未満の瞬停・短い停電   UPS があれば**止まらない**（いちばん多い形）
長い停電                 安全に終了させ、データを守る
```

**いちばん怖いのは、データベースが書いている最中に電源が落ちること。**
2026-09-07 は無事だったが、毎回そうとは限らない。

**9/19 に会員を移すと、お客様のログインもサーバー頼りになる。**
それまでに置いておきたい。家庭用で1万円台から。

## 確かめ方

```powershell
# 高速スタートアップ（0 なら無効）
(Get-ItemProperty "HKLM:\SYSTEM\CurrentControlSet\Control\Session Manager\Power" -Name HiberbootEnabled).HiberbootEnabled

# 電源プラン
powercfg /getactivescheme

# ディスクの停止（0 なら止めない）
powercfg /query SCHEME_CURRENT SUB_DISK DISKIDLE

# 再起動しない時間帯
Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\WindowsUpdate\UX\Settings" |
  Select-Object ActiveHoursStart, ActiveHoursEnd

# 直近の停電・再起動
Get-WinEvent -FilterHashtable @{LogName="System"; ID=6005,6008,1074,41} -MaxEvents 6
```

**GAS の `サーバーの生死を見る()` でも、外から届くかを見られる。**
15分おきの見張りが仕掛けてあり、2回続けて届かないとメールが来る。
