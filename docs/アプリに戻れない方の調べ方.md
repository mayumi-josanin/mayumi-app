**19名は、会員登録と完全に同じお名前を入力しても入れなかった。**
つまりお名前は原因ではない。**電話番号・生年月日のほうが登録されていない。**

復元は「お名前 ＋（電話番号・生年月日・現在のパスコードのいずれか1つ）」で照合する。
ところが試行回数の多い4名は、**電話番号も生年月日も登録が無い**。
パスコードを忘れて復元しようとしている方に「現在のパスコード」を求めているので、
**何度やっても通らない。**

## 調べ方

サーバーPCで、Django のシェルに流し込む。

```powershell
cd $env:USERPROFILE\projects\mayumi-app\server
Get-Content shirabe.py | docker compose exec -T web python manage.py shell
```

### 落とし穴

**PowerShell のパイプは、日本語を壊す。**

- スクリプト側の日本語（変数名も文字列も）が `?` になり、`SyntaxError` になる
- **ASCIIだけで書き、日本語は `\uXXXX` のエスケープで渡すこと**
- データベースから読んだ日本語は、そのまま出しても化けない（壊れるのは送る側だけ）

```python
NG = "失敗"   # 失敗
OK = "成功"   # 成功
```

**`manage.py shell -c '...'` は使えない。**PowerShell が引用符を外してしまう。
**`<` のリダイレクトも使えない。**`Get-Content | ...` のパイプを使う。

### 数えるときの注意

- お名前は**入力された文字列**なので、同じ方が書き分けていれば別々に数えられる。
  「33名」は**上限**であって、実際の人数はそれ以下。
- 失敗の記録の「対象」欄には、**エラー文が入っていて誰の試行かは分からない。**
  詳細（`detail`）の `request.name` を見ること。
- 突き合わせるときは NFKC で正規化し、空白を取り除いてから比べる。
