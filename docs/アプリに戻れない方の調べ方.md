サーバーに移した操作履歴（`records_auditlog`）から、誰がどれだけ困ったかを数えられる。

初めてこれを数えたのが 2026-08-18。以下はそのときの結果と、調べ方。

### 引き継ぎコードは、この場面では使えない

`issueTransferCode` は**管理アプリに画面が無い**（`admin/index.html` に0件）。
お客様のマイページから発行する作りなので、**入れなくなってからでは発行できない。**
93日間で本物の発行が1件も無いのは、これが理由。

**受付から助ける手段は、いまのところ「管理アプリで生年月日を登録する」だけ。**

### 空白は、すでに直っている（2026-08-13）

調べ始めた時点では「姓と名の間の空白で弾かれている」ように見えた。
実際、`金田 有理奈` で11回、`幕内 みさき` で2回失敗している。

しかし `ecf7140`（2026-08-13）「氏名・フリガナから空白を取り除いて二重登録を防ぐ」で
`normalizeNameInput()` が空白を取り除くようになっている。

- 空白入りの失敗は **2026-08-13 以降ゼロ**
- 会員側の登録名に空白があるものは **153名中0件**（入力だけ消えて照合が外れる心配は無い）
- 空白入りでも**成功していた方がいる**（澤田・山口・浦野）

**院長の判断で、ここは触らないことにした（2026-08-18）。**
黙って取り除いて通す今の動きでよい。エラーを出すと、いま通っている入力が通らなくなる。

### 引き継ぎコードの「2件中2件失敗」は問題ではなかった

`issueTransferCode` が2件とも失敗していたが、どちらも `memberId: "MYM-存在しない"` で、
**わざと存在しないIDでエラーの出方を試したもの**だった（2026-08-13）。

ただし**93日間で本物の発行が1件も無い。**引き継ぎコードは使われていない。

## 調べ方

サーバーPCで、Django のシェルに流し込む。

```powershell
cd $env:USERPROFILE\projects\mayumi-app\server
Get-Content shirabe.py | docker compose exec -T web python manage.py shell
```

### 落とし穴

**PowerShell のパイプは、日本語を壊す。**

- スクリプト側の日本語（変数名も文字列も）が `?` になり、`SyntaxError` になる
- **ASCIIだけで書き、日本語は `\uXXXX` のエスケープで渡すこと**
- データベースから読んだ日本語は、そのまま出しても化けない（壊れるのは送る側だけ）

```python
NG = "失敗"   # 失敗
OK = "成功"   # 成功
```

**`manage.py shell -c '...'` は使えない。**PowerShell が引用符を外してしまう。
**`<` のリダイレクトも使えない。**`Get-Content | ...` のパイプを使う。

### 数えるときの注意

- お名前は**入力された文字列**なので、同じ方が書き分けていれば別々に数えられる。
  「33名」は**上限**であって、実際の人数はそれ以下。
- 失敗の記録の「対象」欄には、**エラー文が入っていて誰の試行かは分からない。**
  詳細（`detail`）の `request.name` を見ること。
- 突き合わせるときは NFKC で正規化し、空白を取り除いてから比べる。

## フリガナの状況（2026-08-18）

復元の照合は「**生年月日は必須一致。氏名かフリガナのどちらか一方が一致すればよい**」。
つまり**フリガナはお名前の代わりになる保険**。ところが実際は:

| | 人数 | 割合 |
|---|---|---|
| フリガナが無い | **119 / 153** | 78% |
| フリガナも生年月日も無い | **33** | 22% |
| フリガナがカタカナのまま | 0 | — |

**ほとんどの方が保険を持っていない。**

### 入力の心配は要らない

- `toHiraganaValue()` が**カタカナをひらがなへ自動で寄せる**（`サトウ`→`さとう`）
- `isValidKanaValue()` は `/^[ぁ-ゖー]+$/` なので、**小さい文字も長音符も使える**
- お客様には「ふだんどおり」入れていただければよい

### フリガナが効く場面

**漢字とカタカナが混ざるお名前**（1名）

    佐藤リィリィ（MYM-3820）… フリガナ未登録
    → お名前 `さとうりぃりぃ` を入れておけば、打ち間違えても通る

**お名前がひらがなだけの方**（5名・いずれもフリガナ未登録）

    たかのぶやよい / こばやしみか / たにひらあゆみ / たきざわしえ / しんじょうりえ

この5名は**本来の漢字で入力すると通らない**（登録がひらがなのため）。
フリガナがあれば救われるが、それも無い。

### 受付でお伺いするときは、生年月日とフリガナを一緒に

手間は変わらず、保険が2本になる。
起動時の案内も「生年月日**とフリガナ**がまだご登録されていません」と
両方をお願いする作りなので、方針としても一致している。
