# `ADMIN_TOKEN_SECRET` をサーバーへ渡す手順

段階Bの前に、**GASが作った札をサーバーが同じと判定できるか**を確かめる必要がある。
そのために、GASが署名に使っている秘密をサーバーにも渡す。

**この秘密は変えない。**変えると発行済みの札が全部無効になり、
お客様全員がログイン画面に戻される（[CLAUDE.md](../CLAUDE.md) 絶対ルール1）。

---

## 大事な約束

**秘密を画面に出さない。**

2026-08-16 に、スクリプトを `powershell -Command -` へ流し込んだところ、
**入力がそのまま画面に表示されて秘密が漏れた。**3つ作り直すことになった。

そのため、この手順では

- **値をチャットに貼らない**（開発者が見ないで済む形にする）
- **`scp` でファイルとして渡す**（`-Command` のパイプは使わない）
- **`powershell -File` で実行する**（画面に出さない）
- 渡し終えたら**中間ファイルを消す**

---

## 手順

### 1. GAS から秘密を取り出す（院長の作業）

1. [まゆみの GAS](https://script.google.com/home/projects/1yG73wlHLiOpTzqJMe1XM1a_T6GI54OZ3_MI2MB_ta87eUB9QzQW7YQIL/edit) を開く
2. 左の歯車（プロジェクトの設定）を押す
3. 下の「スクリプト プロパティ」から **`ADMIN_TOKEN_SECRET`** を探す
4. 値をコピーする

**この値をチャットに貼らないこと。**次の手順で直接ファイルに書く。

### 2. Mac にファイルを1つ作る（院長の作業）

デスクトップに `secret.txt` という名前で、**値だけを1行**書いたファイルを作る。

    ADMIN_TOKEN_SECRET=ここに貼り付ける

- 前後に空白を入れない
- 改行は1つだけ（末尾の改行はあってよい）
- **引用符で囲まない**

> テキストエディット.app を使うときは、**「フォーマット → 標準テキストにする」**を
> 先に行うこと。リッチテキストのままだと余計な文字が混ざる。

### 3. サーバーへ渡す（開発者の作業・値は見ない）

    scp ~/Desktop/secret.txt "kazushi kenmochi"@desktop-rmsk0vg.tail8efe0d.ts.net:"C:/Users/kazushi kenmochi/secret.txt"

### 4. `.env` に足す（開発者の作業・値は見ない）

**PowerShell 5.1 は BOM の無い `.ps1` を ANSI として読む。**
日本語を含むスクリプトは文字化けし、**`.env` が0バイトになった前例がある**（2026-08-16）。
そのため、この作業用スクリプトは **ASCII だけで書く。**

サーバーPCで実行する（開発者がリモートから行う）:

    cd $env:USERPROFILE\projects\mayumi-app\server
    powershell -ExecutionPolicy Bypass -File scripts\add-token-secret.ps1 -From "$env:USERPROFILE\secret.txt"

**スクリプトの名前は英字にしてある。**日本語のファイル名を
`-File` に渡すと、PowerShell の文字コード次第で見つからないことがある。

やっていること:

1. `.env` を**先に控える**（`.env.backup-日時`）
2. `secret.txt` を読む
3. `.env` に `ADMIN_TOKEN_SECRET=...` が既にあれば**中身を入れ替える**、無ければ**末尾に足す**
4. 書いたあと**ファイルの大きさを確かめる**（0バイトになっていないか）
5. `secret.txt` を消す

### 5. 反映する

    docker compose up -d

`.env` は起動時に読まれるので、**入れ直しが要る。**
お客様には影響しない（サーバーはまだ写しで、誰も見ていない）。

### 6. 入ったことを確かめる（値は出さない）

    docker compose exec -T web python -c "import os; s=os.environ.get('ADMIN_TOKEN_SECRET',''); print('入っているか:', bool(s), '/ 文字数:', len(s))"

**文字数だけを見る。**値は出さない。

### 7. 札が通ることを確かめる

`gas/札を確かめる.js` の `札を確かめる()` で見本の札を作り、
サーバー側で検証して `MYM-0000-TEST` が返ることを確かめる。

そのあと、**本物の札でも1つ**確かめる。
（お客様の端末にあるもの。管理アプリから1つ発行しても同じ。）

**両方が通るまで段階Bには進まない。**

## うまくいかないとき

| 症状 | たぶんこれ |
|---|---|
| `.env` が0バイトになった | スクリプトの文字化け。控えから戻す |
| 文字数が合わない | `secret.txt` に引用符や空白が混ざっている |
| 札が通らない | 秘密が違う。GAS のプロパティをもう一度見る |
| それでも通らない | **切り替えない。**原因が分かるまで写しのまま置く |

`.env` の控えは `.env.backup-日時` として同じ場所にある。戻すときは名前を戻すだけ。
