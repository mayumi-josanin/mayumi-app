# 秘密の点検

**2026-08-25 に、4つのアプリの動作確認をしたときの記録。**

---

## 見つかったこと

ビジリスの `TOKEN_SECRET`（管理者の札に署名する秘密）が**未設定**で、
`bijiris/gas/Code.gs` に書かれた既定値がそのまま使われていた。

**そしてこのリポジトリは公開されている。**

管理者の札はこう作られる。

    makeToken_(ユーザー名, 期限) → { u, exp, sig }
    sig = HMAC-SHA256("ユーザー名|期限", TOKEN_SECRET)

`verifyToken_` は**署名と期限しか見ていない。**
**ユーザー名が実在するかを確かめていない。**

> つまり秘密が既定のままだと、**公開コードを読んだ人が管理者の札を
> 自分で作れる。パスワードは要らない。**
> その札で **29か所**の管理操作（お客様の氏名・計測値・写真など）が通る。

### 記録が間違っていた

2026-08-11 の申し送りには「✅ 64文字を設定済み」とあった。**本番は未設定だった。**

> **「対処済み」と書いた記録を信じない。本番を実測する。**

## いまの状態

| | 状態 |
|---|---|
| ビジリス `TOKEN_SECRET` | **設定済み**（64文字） |
| ビジリス `ADMIN_PASSWORD` | 変更済み（既定値と違う） |
| ビジリス `ADMIN_USERNAME` | **既定値のまま**（公開コードで分かる） |
| ビジリス 計測写真の共有 | **`ANYONE_WITH_LINK` のまま**（未対処） |
| まゆみ `ADMIN_TOKEN_SECRET` | 設定済み。**絶対に変えない** |

### 残っている2つ

**① `ADMIN_USERNAME` が既定値のまま**

パスワードが変わっていて、札も偽造できなくなったので、影響は小さい。
それでも「ユーザー名が公開されている」状態ではある。

**② 計測写真が「リンクを知っている全員が閲覧可」**

`Code.gs` の 3283 行ほか7か所で `ANYONE_WITH_LINK` にしている。
URLは推測できないが、**一度漏れれば誰でも見られる。**
お客様のお体の写真なので、扱いを決め直す必要がある。
