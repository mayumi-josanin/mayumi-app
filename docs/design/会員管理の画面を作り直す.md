# 会員管理の画面を作り直す

**2026-09-07。院長のご要望から。**

> 会員情報の全てが一覧として見れて編集することができないため、
> 会員情報は全て会員管理で管理できるようにしたい。
> 現在スプレッドシートで管理している会員情報は全て

---

## なぜ、いま必要なのか

**移行を止める要件。**9/19に会員をサーバーへ移すと、

```
移行前   シートを直接直せる  → アプリに反映される
移行後   シートを直接直しても → **どこにも反映されない**
```

シートは過去の控えになる。**いまシートで直しているものが、管理アプリで
できないと、その項目は誰にも直せなくなる。**

## いまの状態（実測）

```
シートが持つ項目        34
管理アプリで見える       17ほど
管理アプリで編集できる   **6項目のみ**
   氏名・フリガナ・電話番号・生年月日・住所・メモ
```

スタンプ数と特典は別画面（スタンプ・特典管理）にある。それ以外は
**シートを直接触るしかなかった。**

---

## 決めたこと

### 編集できる（12項目）

```
氏名  フリガナ  電話番号  生年月日  住所  メモ
現在スタンプ数  スタンプカード番号  最終スタンプ取得日  最終スタンプ取得日時
権限  ビジリス  LINEユーザーID
```

- **電話番号は先頭の0を自動で戻す。**2026-08 に121件、9/7 にさらに4件
  直している。**入力のたびに整える。**
- **LINEユーザーIDは重複を許さない。**2人に同じIDを付けると、
  予約システムで記録が混ざる。

### ボタンで操作する（3つ）

| | なぜ自由入力にしないか |
|---|---|
| **パスコードを設定** | 移行後は**ハッシュ**で保存する。見ることはできない。「忘れた」ときに新しく設定する |
| **引き継ぎコードを発行** | 8桁・重複なし・1週間有効。**手で入れると他の方と重なり、別の方の記録が復元される** |
| **通知を止める** | この欄は入/切ではなく**届け先そのもの**（長い英数字）。手で書き換えると通知が届かなくなる。再開はお客様の端末から |

### 見えるだけ（5項目）

```
会員ID  登録日時  最終オンライン日時  統合先会員ID  登録経路（＋詳細・更新日時）
```

**会員IDを変えるとお客様が入れなくなる。**統合先を手で変えると、
統合の履歴の辻褄が合わなくなる。

### 画面に出さない（2項目）

```
パスワードハッシュ  パスワードソルト
```

**パスコードを暗号にした値そのもの。**中途半端な値を入れると
その方がアプリに入れなくなる。人が読める値でもない。

### 一覧にも出す

いまは編集フォームを開かないと見えない項目がある。**一覧で見比べられる
ようにする。**列が多くなるので、表示する列を選べるようにする。

---

## 作る順番

```
① サーバー側の窓口を広げる（updateAdminUser に項目を足す）
② パスコードを設定する窓口を作る
③ 管理アプリの編集フォームを広げる
④ 管理アプリの一覧に列を足す（表示列を選べるように）
```

**①②はサーバー側なので、いま作っても本番に影響しない。**
③④は管理画面が変わるので、確認いただいてから `main` に入れる。

## 忘れないこと

- **⑨ 入力してみる。**保存して、一覧に出て、開き直しても残るか
- **⑩ 書き込む窓口を数える。**シートに書いたままのものが無いか
