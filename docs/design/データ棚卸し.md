## 見落としやすい保管場所：スクリプトプロパティ

**スプレッドシートを見ているだけでは気づかないが、ビジリスGASは28個のプロパティにも
実データを持っている。**移行時にここを忘れると、アンケートの設問そのものが消える。

| 鍵 | 中身 | 移行の要否 |
|----|------|-----------|
| `SURVEYS_JSON` | **アンケートの定義そのもの** | **要** |
| `CUSTOMER_PROFILES_JSON` | お客様情報 | **要** |
| `CUSTOMER_MEMOS_JSON` | お客様ごとのメモ | **要** |
| `TICKET_SURVEY_META_JSON` | 回数券の進行状況 | **要** |
| `TICKET_SURVEY_PROMPT` | AI分析の指示文 | **要** |
| `NEXT_MEMBER_NUMBER` | 会員番号の採番 | **要** |
| `ADMIN_USERS_JSON` / `ADMIN_USERNAME` / `ADMIN_PASSWORD` | 管理者 | 要（作り直しでも可） |
| `AUDIT_LOGS_JSON` / `ERROR_LOGS_JSON` | 履歴・エラー | 任意 |
| `LOGIN_ATTEMPTS_JSON` / `OTP_SESSIONS_JSON` | 一時データ | 不要 |
| `ANTHROPIC_API_KEY` / `ONESIGNAL_*` | 外部サービスの鍵 | 設定として移す |
| `*_TRIGGER_IDS_JSON` / `*_SPREADSHEET_ID` / `BACKUP_META_JSON` | 内部の覚え書き | 不要 |

まゆみ側のGASにも同様のプロパティがある（`ADMIN_TOKEN_SECRET` を含む）。
**`ADMIN_TOKEN_SECRET` は移行先へそのまま持っていく必要がある**（これが変わると全員がログアウトされる）。

## 分かったこと

1. **規模は問題にならない。** 操作履歴を除けば実データは900行ほど。どのデータベースでも余裕。
2. **未使用の列と表が多い。** 会員データの33列中7列、注文管理・SUPPORT_CHAT_LOG・ADMIN_TEMPLATESの3表は
   一度も使われていない。移行先ではこれらを作らない。
3. **会員データに欠けがある。** 172名のうち
   - 氏名なし … 4名
   - 電話番号なし … 41名
   - 生年月日なし … 47名
   - **パスコードなし … 35名**
   - フリガナあり … 34名のみ
4. **パスワードハッシュ方式を使っているのは2名だけ**（管理者2名）。
   残り170名は「パスコード」列での照合。移行先でも両方に対応する必要がある。
5. **アンケート定義はスプレッドシートではなくスクリプトプロパティにある。**
   移行計画で最も忘れやすい部分。

## この棚卸しをやり直すには

Apps Script（ビジリス）で `棚卸し.gs` → `棚卸しをする()` を実行する。
新しいスプレッドシートに書き出され、ログにURLが出る。
片付けは同じファイルの `棚卸しのファイルを消す()`。
