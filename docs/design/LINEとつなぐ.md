# LINEとつなぐ

**2026-09-08 の下調べ。**院長から
「お客様アプリにログインした方で、LINEIDが登録されていない人に
友だち登録のご案内を出せないか。そうすればLINEIDを取得できる」と伺った。

**着手は 9/19 のあと**（院長のご判断）。会員の表がサーバーへ移ってから作る。
いま作ると保存先がスプレッドシートなので、9/19 に作り直しになる。

---

## いちばん大事なこと

**「友だち追加してください」の案内だけでは、LINEIDは取れない。**

友だちになると、LINEから当院へ webhook が届く。
中身は「`U1fd6…` が友だちになった」だけで、**それが誰かは書いていない。**

これはポチコで当たった壁とまったく同じ（[ポチコの顧客を結ぶ] 参照）。

```
友だち          484名   IDは分かる。誰かは分からない
ポチコで予約     261名
  表示名で一意   180名
    本名も取れる 131名   ← 突き合わせられたのはここだけ
  友だちにいない  75名   ← 手が届かない
```

案内を出して友だちが増えても、**「増えたIDが誰か」を当てる作業がまた発生する。**
表示名で当てるのは同姓同名と同じ危険を持つ（CLAUDE.md「お名前でお客様の記録を探す」）。

## だから「LINEでログイン」にする

アプリには**すでに会員としてログインしている。**
そこで LINE ログインを1回挟めば、**どの会員のIDかが確実に決まる。**推測が要らない。

```
① アプリにログイン           今のまま（会員IDとパスコード）
② LINEIDが空なら案内を出す    まだ友だちでない方にだけ出せる
③ 「LINEとつなぐ」を押す      LINEの確認画面。友だち追加のチェック付き
④ 戻ってきたら確かめて保存     サーバーがLINEへ問い合わせ、34列目へ
```

**③で友だち追加も同時に済む。**院長のお考えのご案内は、この中に含まれる。
LIFF の「友だち追加オプション」を on にすると、確認画面に友だち追加が並ぶ。
`liff.getFriendship()` で友だちかどうかを読めるので、**出す相手を絞れる。**

## 揃っているもの・足りないもの

```
○ LINEログインのチャネル      mayumi-reserve で動いている
○ 公式アカウントと同じ提供元   2026-09-05 に確認済み
                             （違う提供元だと、同じ人でもIDが別物になる）
○ 会員シートの34列目          USER_COL.LINE_USER_ID
○ サーバーの保存先            Member.line_user_id（重複を弾く作り入り）
○ 本物か確かめる処理          mayumi-reserve の apps/booking/line.py

× LIFFの登録                  アプリのURLを登録する。**院長の作業**
× 確かめる窓口                サーバーに1つ足す
× 画面                        ご案内と、つなぐボタン
```

## 気をつけること

**① アプリが送ってきたIDを信じない。**
必ずサーバーからLINEへ問い合わせて確かめる。信じる作りにすると、
**誰でも他人のIDを名乗れる。**line.py の `looks_like_our_token` →
LINEへ verify、の順はそのまま使える。

**② 同じLINEを2人に付けない。**
ご夫婦で1台という場合がある。`admin_member.py` に重複を弾く作りは
入っているが、**弾いたときにお客様へ何と出すか**が未決。

**③ 飛ばせるようにする。**
LINEをお使いでない方、つなぎたくない方がいる。
**ログインを止める作りにしない。**

**④ iPhoneでホーム画面から開いた場合。**
LINEの画面へ行って戻る間に、アプリの状態を保てるか。
**実機で確かめるまで言い切れない。**ここだけ机上で判断しない。

## 何のために集めるか（2026-09-08 に伺えた）

```
お客さんの一元管理をLINEIDで行いたい
予約システムの中で、予約者の情報を一つの会員情報から拾ってきたい
```

**この案内は、その入口になる。**台帳の `line_user_id` が空のままでは
予約システムが会員を引けないので、**ここを先に済ませないと先へ進めない。**

形は [お客様台帳を1つにする](お客様台帳を1つにする.md) に書いた。
